# Codex

Codex reads [`AGENTS.md`](../AGENTS.md). Follow that protocol.

This rule exists so a Codex session that looks in `.codex/` still finds the memory-bank loop.

- Collection / protocol / `_template` → `_collection/memory-bank/`
- Work in an agent folder → that folder's `memory-bank/`
- No shared bank

Before work: read `PROTOCOL.md`, `progress.md`, `active-context.md`, `decisions.md`.
After work: update `progress.md` and `active-context.md`. Decisions → `DEC-NNN` in `decisions.md`.
