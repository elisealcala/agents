# Decisions — career-assistant

## DEC-001: Establish the personal-use design before selecting a runtime

Date: 2026-10-30
Status: accepted
Context: The user explicitly returned to the small career-assistant idea as a way to reengage with the repository. Earlier chat research had not produced a working agent. This turn selects direction, rather than specifying a runtime or asking for a full implementation.
Decision: Establish a bounded first-milestone design in this independent agent folder. Select the runtime before runtime implementation; none is selected by this scaffold. The user-confirmed purpose is personal job/freelance usefulness, across their existing specialty and AI-focused work, remotely from Peru now.
Consequences: No dependency installation, model configuration, CI registration or working-agent claim in this design slice. Broader personal goals do not expand this agent's initial task.

## DEC-002: Evidence and uncertainty are part of the first review

Date: 2026-10-30
Status: accepted
Context: A prior manual shortlist found stack overlap but application questions exposed specialized experience that the supplied résumé did not establish. Remote/LATAM labels also did not guarantee Peru eligibility.
Decision: The initial design distinguishes direct experience evidence, related evidence and missing evidence; eligibility conclusions require source text. Application screening questions are additional input. Missing evidence must not be rewritten as lack of experience, and proposed recommendations are not user decisions.
Consequences: Reviews need source identifiers, explicit uncertainty and a next action. Job/source content cannot instruct the agent to invent or approve candidate claims. Personal contribution and measured scale require their own evidence.
